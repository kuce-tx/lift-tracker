# Lift Tracker

A personal lift-tracking PWA. All workout data stays in the browser (`localStorage`); nothing is sent to a server.

Open it at [https://kuce-tx.github.io/lift-tracker/](https://kuce-tx.github.io/lift-tracker/).

There is no visible workout clock. The rest timer starts only when you tap it. Each set and each workout can have a note, and those notes are included in the CSV. Mark an exercise Done to lock it. Press and hold, or swipe, to delete; deletion asks you to confirm and can be undone. Share workout exports the session as a CSV.

## Add to your home screen

**iPhone:** Safari > Share > Add to Home Screen

**Android:** Chrome > menu > Install app
